# مراجعة الكود

1. اقرأ الفرق فقط (الملفات المعدّلة)، ولا تعد قراءة المشروع كله.
2. ابحث عن: دوال مستدعاة ولم تُعرّف (خصوصًا بعد استبدال كتل كبيرة)، وتعليمات SQL بتركيب نصي، وتغييرات في الصلاحيات، ومنطق مكرر، ومتغيرات غير مستخدمة.
3. في الواجهة: تأكد أن كل `${...}` يحوي نصًا مهربًا بـ `esc()` أو قيمة رقمية.
4. تحقق من أن أي دالة مستدعاة معرّفة: `grep -n "function NAME\|const NAME="`.
5. اعرض الملاحظات مرتبة حسب الخطورة، مع رقم السطر.
