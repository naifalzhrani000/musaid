# كفاءة التوكن

1. ابحث أولًا بـ `grep -n` ثم اقرأ نطاقًا محددًا (`view_range`)، ولا تقرأ `index.html` (60+ كيلوبايت) كاملًا.
2. عدّل بتغيير مستهدف (`str_replace` أو Python مع `assert count == 1`)، لا بإعادة كتابة ملف كامل.
3. لا تعد تشغيل الاختبارات كلها إذا كان التغيير في جزء واحد، إلا قبل التسليم.
4. لخّص التقدم في سطرين بعد كل مرحلة.
5. لا تعرض الكود في الرد إلا إذا طُلب.
