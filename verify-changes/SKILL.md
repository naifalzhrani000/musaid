# التحقق من التغييرات

الفحوص المتاحة فعلًا:
- `node --check server.js`
- فحص صياغة JavaScript في الصفحة: استخرج الكتلة من `<script>` ثم `new Function(code)`.
- `node --test test.mjs` (الاختبارات تشغّل الخادم بنفسها).
- متصفح (Playwright) لصفحات الجوال: الأخطاء البرمجية، والتمرير الأفقي.

لا توجد TypeScript ولا Lint ولا Build في هذا المشروع، فلا تدّعِ نجاحها.
اعرض نتيجة كل فحص كما ظهرت، وإذا فشل فأصلح ثم أعد التشغيل.
